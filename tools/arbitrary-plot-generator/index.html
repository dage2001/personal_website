Data & visualization

Arbitrary Plot Generator

CSV data and LaTeX functions. One consistent style, ready to export.

Add data

Choose one X column and one or more Y columns. Empty pairs are skipped; nonnumeric values are reported. Files stay in your browser.

An explicit y= or x= sets the form automatically. For x=f(y), ranges and marker coordinates use y.

Supported expressions

Use x for y=f(x), or y for x=f(y), along with real numbers, π, e, arithmetic, fractions, powers, roots, abs, exp, ln, log (base 10), sin, cos, tan, inverse trig, sinh, cosh and tanh. Trig uses radians. Optional y=, x= and math delimiters are accepted.

Finite sums and products are supported: \sum_{k=1}^{5} x^k and \prod_{k=1}^{3}(x+k). Supply an index and finite integer bounds, independent of the input coordinate. Nested bounds may depend on an outer index. Limit: 1,000 terms per sum/product, 10,000 total terms per evaluation. Infinite or unbounded series, piecewise expressions, integrals, arbitrary functions and free variables other than the chosen input coordinate are unsupported.

Figure settings

Axis labels, title, caption and legend names support inline $math$.

Baseline is Y for y=f(x), and X for x=f(y).

Color palette

Select colors individually in each series. Reference palette sampled from the supplied Nature low saturation color card.
