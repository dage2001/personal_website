SVG source code

Inspired by Thomas Lochmatter’s LaTeX to SVG. Supports MathJax’s TeX math syntax. SVG glyphs are exported as paths for use in figures, slides, and vector editors. MathJax loads from a CDN; equations stay in your browser.
